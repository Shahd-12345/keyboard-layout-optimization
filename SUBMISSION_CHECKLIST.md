# Final Submission Checklist

Before creating the GitHub release and submitting the IEEE PDF:

- [ ] Add all three group-member names, student IDs, and affiliations to the
      notebook and IEEE author block.
- [ ] Review the executed notebook once; do not clear its outputs.
- [ ] Confirm `python -m unittest discover -s tests -v` reports 26 passing tests.
- [ ] Confirm `python scripts/validate_final_repository.py` passes.
- [ ] Upload the extracted repository contents, not the outer ZIP, to GitHub.
- [ ] Verify the GitHub notebook preview contains the executed Brown Corpus
      results and figures.
- [ ] Create a `v1.0-final` GitHub release or copy the exact final commit URL.
- [ ] Insert that permanent URL in the paper's reproducibility/data-availability
      statement.
- [ ] Use only the audited final values from `RESULTS_SUMMARY.md`.
- [ ] Do not report smoke-test numbers.
- [ ] Do not claim statistically significant adaptive superiority.
- [ ] Do not claim human typing-speed or ergonomic benefits without user tests.
- [ ] Compile the paper in the official IEEE template and check every equation,
      reference, table, and figure at 100% zoom.
- [ ] Ensure the final paper is six pages including references.
- [ ] Name the submitted PDF according to the instructor's required convention.
